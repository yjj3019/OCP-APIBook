# 데이터 수집

`scrape.js`는 Playwright의 `run_code` 용 함수입니다(`async (page) => { ... }`). 브라우저 6개 탭으로
**4.22 / 4.21 / 4.20** 의 개요 페이지(가이드 + API 목록)와 API 레퍼런스 북 25~26개를 병렬로 읽어
각 API의 설명, 최상위·중첩 필드, 엔드포인트(메서드·쿼리 파라미터·요청 본문·응답)를 추출합니다.

1. `scrape.js` 를 Playwright 환경에서 실행합니다(약 8~9분, 렌더링 안정화를 기다립니다).
2. 결과는 마지막에 `about:blank` 탭의 `window['__v4.22']` 등에 남습니다. 버전별로 `_scrape/v4.22.json` 처럼 저장합니다.
3. 저장소 루트에서 `node build.js` 를 실행하면 `data/` 가 다시 만들어집니다.

`_scrape/` 는 중간 산출물이라 저장소에 포함하지 않습니다(`.gitignore`).
