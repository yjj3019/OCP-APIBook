## 실행 조건

- Chrome·Edge와 320~1440px 화면에서 로컬 index.html을 열었습니다. 오프라인 검사는 저장소 서버에서 필요한 문서를 먼저 연 뒤 브라우저 네트워크를 차단했습니다. CSV의 빈 릴리스 칸은 해당 시나리오가 여러 고정 릴리스를 직접 선택하는 경우입니다.
- OCP 4.20, 4.21, 4.22, 5.0을 분산했습니다. 언어별 메뉴 검사는 각 회차에 6개 메뉴, 각 분류의 조회 결과, 모든 가이드 본문, 그래프 회전과 노드 선택을 확인했습니다.
- REST는 로컬 시뮬레이터의 요청·응답을 확인했습니다. 원본 갱신과 클립보드는 테스트용 응답·수신기를 사용했습니다. MCP/CLI는 동일한 입력의 실제 표준 입출력과 기대값을 비교했습니다.

## 처음 발견한 문제와 재검증

- 한국어·영어에서 상단 검색 버튼이 열리지 않았고 단축키로 열어도 입력 결과가 갱신되지 않았습니다. 지연 로딩 이후에도 클릭·키보드 이벤트를 등록하도록 수정했습니다.
- 첫 메뉴 검사에서는 768px 한국어와 320px 영어에서 닫힌 메뉴의 다음 링크를 누르다가 시간 제한에 걸렸습니다. 현재 메뉴를 다시 누를 때 메뉴판이 남는 동작도 별도로 재현했습니다. 클릭 시 메뉴를 닫고, 검사에서는 화면 교체와 닫힘을 확인한 후 계속하도록 수정했습니다.
- 한 한국어 오프라인 시나리오는 네트워크 차단 전 초기 메뉴를 5초 안에 찾지 못했습니다. 최초 지연의 원인은 확정하지 않았습니다. 최종 메뉴와 오프라인 검사는 각각 두 언어에서 전체 10회씩 다시 실행했습니다.
- 설정 지우기에서는 구형 localStorage 초안은 삭제되고 IndexedDB 초안은 남았습니다. 화면 설정·탐색 기록 삭제 범위를 명시했습니다. 초기화 직후 홈에 남아 있던 즐겨찾기를 발견해 홈 목록과 상세 별표가 즉시 갱신되도록 수정했고, 두 형식의 초안은 전용 삭제 버튼으로 함께 지우는지 재검증했습니다.
